# Цементная мельница — настольное приложение PySide6

Оконная исследовательская модель **одного барабана с одной или двумя камерами**. Интерфейс полностью на **PySide6 (Qt 6)**, без Tkinter, Streamlit или браузера. Математическое ядро и экспорт Excel остались самостоятельными Python-модулями.

> Результаты без калибровки являются демонстрационным прогнозом, а не подтверждёнными замерами цементного завода.

## Запуск на Fedora и в PyCharm

```bash
cd ~/Downloads/melnitsa-proj
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

В PyCharm выберите `.venv/bin/python` в качестве интерпретатора и запускайте **`main.py`** кнопкой Run. Если ранее использовалось существующее `.venv`, достаточно обновить зависимости: `.venv/bin/python -m pip install -r requirements.txt`. Отдельно устанавливать `python3-tkinter` не требуется.

При проблемах с Qt в Fedora проверьте системные зависимости графической среды и наличие пакетов `xcb`; запускать приложение нужно в графическом сеансе. Для тестов в CI используется `QT_QPA_PLATFORM=offscreen`.

## Возможности

- **Барабан и камеры.** Один барабан, 1–2 камеры; независимые внутренние диаметры и длины, обороты, измеренная мощность. Общая длина рассчитывается автоматически, физический диаметр камеры не меняется от износа мелющих тел.
- **Подача и клинкер.** Измеренная подача либо выпуск/время, интервалы Q(t), импорт входного грансостава CSV, лабораторного Wi Бонда JSON, абразивности и размолоспособности. F80 рассчитывается из фракций входного клинкера, P80 — из модельного выхода. Wi эксплуатации не является лабораторным Wi.
- **Износ.** Прогноз по времени, остаточная масса, текущий диаметр мелющих тел, удельный износ по фракциям и рекомендации догрузки.
- **Сита.** Стандартные и пользовательские размеры, выбор для диаграммы помола и таблицы проб; контроль R0,08 и R0,045 считается независимо от выбора сит.
- **Мелющие тела / догрузки.** Редактирование строк в таблицах Qt. Новая догрузка создаётся сразу со стандартными значениями, без всплывающего окна. Фракции могут отличаться по форме, материалу, диаметру и массе.
- **Обзор.** Шесть диаграмм, включая производительность Q(t), накопленный выпуск, общий износ и средние диаметры мелющих тел по камерам. Масштабирование графиков через панель Matplotlib.
- **Excel.** Кнопка экспорта готовит таблицы и встроенные диаграммы `.xlsx` через `XlsxWriter`.

Поля пересчитываются автоматически через 650 мс после изменения корректного значения; при вводе ошибочных данных старая диаграмма не выдаётся за новую, а причина ошибки отображается внизу окна.

## Структура

```text
main.py                  # запуск приложения (PySide6)
project/
  qt_app.py              # окна, формы, графики и импорт
  ui_data.py             # преобразование/проверка данных UI без Qt
  model.py               # математическое ядро, имитация износа и помола
  excel_export.py        # Excel с таблицами и графиками
  calibration.py         # импорт CSV истории, оценка расхода
  blackbox_cli.py        # отдельный интерфейс расчёта через JSON
  app.py                 # альтернативный запуск приложения
examples/                # файлы для импорта, не исполняемые сценарии
  mill3_input.json
  one_chamber_input.json
  variable_feed_input.json
  clinker_fractions.csv
  lab_bond_test.json
  history_input.csv
tests/                   # модельные, экспортные и Qt smoke-тесты
requirements.txt
requirements-dev.txt
```

## Проверка

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q
```

Импортируйте конфигурацию из `examples/` через меню **Файл → Импорт параметров JSON**. Файлы `model.py` и `blackbox_cli.py` сохранены для машинного вызова Black Box без интерфейса.

**Физические ограничения:** лабораторный индекс Бонда определяется до помола по протоколу; без испытания значение не подменяется расчётом из размера барабана. Производительность сама по себе не становится переменной от износа: для этого нужен измеренный график Q(t) или калиброванная зависимость.
