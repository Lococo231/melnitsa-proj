# Цементная мельница

Настольное приложение на Python и PySide6 для исследовательского моделирования
помола цемента, износа мелющих тел, расчёта показателей качества и рекомендаций
по догрузке/выгрузке. Рабочий интерфейс — на русском языке.

## Запуск (Windows, Python 3.11)

```powershell
cd C:\Users\Lococo\Desktop\melnitsa
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Для повторного запуска достаточно последней команды.

## Сборка Windows EXE

На Windows выполните в корне проекта:

```powershell
.\build_windows.cmd
```

Результат: `dist\CementMill.exe` (сборка PyInstaller OneFile). Пользователю
можно передать один EXE без Python и исходников. Сначала проверьте EXE на
другом компьютере.

Для диагностики запуска и сборки в папку:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_windows.ps1 -Mode OneDir -Console
```

В этом случае передавайте **всю** папку `dist\CementMill\`.

## Что нужно для программы

- `main.py` — основная точка входа.
- `project/` — исходники модели, интерфейса, симуляции, графиков и экспорта.
- `requirements.txt` — библиотеки для запуска.
- `requirements-build.txt`, `build_windows.cmd`, `scripts/build_windows.ps1` — сборка EXE.

Остальная документация, старые установщики обновлений, тесты и демонстрационные
данные удалены из рабочей ветки, поскольку для запуска и сборки не требуются.
При необходимости старые материалы доступны в истории Git.

## Ограничения

Модель исследовательская: расчётный Блейн не заменяет лабораторное измерение,
а прогноз износа/качества и рекомендации требуют заводской калибровки. Анимации
помола демонстрационные, не промышленный DEM-расчёт. Связь загрузки с
производительностью и физическая непрерывность состояния между отдельными
отрезками симуляции ещё нуждаются в доработке.
