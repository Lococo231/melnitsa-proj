# Cement Wear Black Box — моделирование цементной мельницы

Python-прототип веб-интерфейса и расчётного ядра для имитационного моделирования помола, износа мелющих тел и планирования догрузок. Приложение построено на Streamlit и позволяет выгружать таблицы и диаграммы в Excel.

> **Статус:** исследовательский прототип. Демонстрационные параметры и результаты не являются подтверждёнными измерениями предприятия. Законы износа и коэффициенты требуют калибровки по журналу догрузок и натурным замерам.

## Структура

```text
cement-wear-blackbox/
├── project/                 # Исполняемый код: Streamlit, ядро, Excel, CLI
│   ├── app.py               # Веб-интерфейс
│   ├── model.py             # Помол, износ, расчёт параметров и догрузок
│   ├── calibration.py       # Обработка истории замеров
│   ├── excel_export.py      # Экспорт XLSX через XlsxWriter
│   ├── blackbox_cli.py      # Внешний интерфейс JSON -> JSON
│   └── run_example.py       # Создание демонстрационного XLSX и JSON
├── examples/                # Образцы параметров и результатов
│   ├── example_config.json
│   ├── example_blackbox_result.json
│   ├── example_results.json
│   └── example_report.xlsx
├── tests/                   # Автоматические тесты модели и Excel
├── docs/                    # Анализ предметной области и формулы
│   └── MODEL_AND_DOMAIN.md
├── legacy_web/              # Исторический самостоятельный HTML-прототип
├── .github/workflows/       # Тестирование при коммитах и PR
├── .gitignore               # Исключение .venv и временных файлов
├── pytest.ini
├── requirements.txt
└── requirements-dev.txt
```

## Запуск на Fedora / Linux

Из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run project/app.py
```

Веб-сайт обычно доступен по адресу `http://localhost:8501`.

## Расчёт Black Box через CLI

```bash
python project/blackbox_cli.py examples/example_config.json outputs/result.json
```

До запуска создайте папку вывода: `mkdir -p outputs`. Скрипт ожидает уже существующую родительскую папку.

## Создание Excel и примеров

```bash
python project/run_example.py
```

Результаты записываются в `examples/` и заменяют соответствующие демонстрационные файлы.

## Проверка

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Публичные зависимости доступны из PyPI; закрытая `artifact_tool_v2` **не требуется**.

## Назначение папок

- **project/** — исходный код приложения и математическое ядро.
- **examples/** — демонстрационные конфигурации, результаты и отчёт Excel с диаграммами. Не используйте как заводские исходные данные.
- **tests/** — регрессионные тесты.
- **docs/** — подробная постановка задачи, описание входных параметров и функция износа.
- **legacy_web/** — предыдущая HTML-версия симулятора, самостоятельная и не подключённая к Python-ядру.

## Ограничения

Приложение не подключено к реальной АСУ ТП и не содержит проверенной регрессии по заводским замерам; Блейн пока оценивается эмпирически. Для промышленного применения необходимо верифицировать модель и выполнить калибровку на данных предприятия. Лицензия на распространение проекта пока не определена.
