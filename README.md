# Мельница — настольная имитационная модель

Оконное приложение **«Цементная мельница»**: один барабан с **одной или двумя камерами**. Пользователь задаёт длины и внутренние диаметры камер, размеры/материалы шаров и цильпебса, измеренные параметры режима, время моделирования и догрузки. Расчёт помола, износа, R-сит, P80 и эксплуатационного Bond Work Index — в Python. Графики и таблицы экспортируются в Excel.

> Это исследовательская модель, не откалиброванная по данным цементного предприятия. Wi эксплуатации не является лабораторным Bond Ball Mill Work Index.

## Запуск на Fedora / PyCharm

```bash
sudo dnf install python3-tkinter
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Откройте `main.py` в PyCharm и нажмите Run. Браузер не используется.

## Входные данные

- **Барабан и камеры:** один барабан, 1–2 камеры, независимо задаются длина и внутренний диаметр каждой камеры. Общая длина = сумма длин камер + толщина перегородки. Внутренний Ø камеры ограничен номинальным Ø барабана.
- **Подача:** измеренная производительность или выпуск/время. Выход Q нельзя надёжно вычислить только по геометрии.
- **Клинкер:** фракционный состав импортируется из `examples/clinker_fractions.csv` либо полного JSON. Его свойства и лабораторный протокол Бонда импортируются из JSON; F80 и лабораторный Wi отображаются в «Подача и клинкер» и рассчитываются автоматически при наличии исходного протокола.
- **Сита:** галочки для стандартных сит, добавление своего диаметра, до 20 сит. Остатки R0.08 и R0.045 считаются независимо от галочек.
- **Догрузки:** отдельные новые партии по часам, камерам, диаметрам и материалам.

## Что такое Bond Wi, F80 и P80

**F80** — размер (мкм), через который проходит 80% массы входного материала. Из модельных классов получается логарифмической интерполяцией и не вводится вручную. **P80** — аналогичный размер на выходе, рассчитывается моделью. **Wi лабораторный** — показатель, получаемый *до работы мельницы* из отдельного лабораторного испытания. В приложении вычисляется из импортированных `closing_sieve_um`, `gpr_g_rev`, `f80_um`, `p80_um` по формуле Бонда. Без протокола выводится «нет протокола»: число нельзя честно вычислить из одной геометрии мельницы.

**Wi эксплуатационный** оценивается по измеренной мощности, Q и расчётным F80/P80: `Wi_op = (P/Q) / [10 × (1/√P80 − 1/√F80)]`; при этом P80 и помол в прототипе не калиброваны, поэтому оценка не заменяет лабораторное испытание. Обычный способ повысить/понизить производительность — изменить подачу, режимы и загрузку, но это не значит, что можно поменять свойства самого клинкера.

## Примеры для импорта

- `examples/mill3_input.json` — двухкамерный барабан
- `examples/one_chamber_input.json` — однокамерный барабан
- `examples/clinker_fractions.csv` — 10 фракций клинкера (колонки `class,percent`)
- `examples/history_input.csv` — заводской журнал для оценки среднего расхода мелющих тел
- `examples/lab_bond_test.json` — **условный** протокол лабораторного испытания Бонда (для импорта через меню «Файл»).

Для тестов: `python -m pip install -r requirements-dev.txt` и `python -m pytest -q`.

## Интерфейс и происхождение параметров

- **Барабан и камеры**: геометрия, обороты и измеренная мощность.
- **Подача и клинкер**: подача, влажность/температура, импорт фракционного состава и лабораторного протокола Бонда; F80 рассчитывается автоматически.
- **Прогноз износа**: только период, шаг и порог рекомендации; базовый коэффициент износа и показатель Δ доступны для просмотра, калибровка из журнала CSV.
- **Сита**: набор контрольных сит для графика и таблицы проб.
- **Мелющие тела / Догрузки**: размеры, массы, материал и операции догрузки.
- **Обзор**: результаты — остатки, прогноз износа, P80 и эксплуатационный Wi.

В оконном режиме вкладки адаптивны: когда ширины недостаточно, вместо обрезанных названий появляется выпадающий список с полными названиями разделов. В верхнем меню «Файл» находятся импорты и экспорт.

Для расчёта лабораторного Bond Wi применяется формула `44.5 / (P1^0.23 · Gpr^0.82 · (10/√P80 − 10/√F80)) × 1.10231131` (кВт·ч/метрическую тонну). *P80 в этой формуле относится к лабораторному тесту*, а не к производственному выходу мельницы. Источники: [SME / GMG](https://www.ceecthefuture.org/wp-content/uploads/2015/12/Bond-GMSG-SME-conference.pdf), [GMG Bond efficiency](https://gmggroup.org/wp-content/uploads/2024/07/GUIDELINE__Determining-the-Bond-Efficiency-of-Industrial-Grinding-Circuits_2021.pdf).
