# Melnitsa Project — настольная модель цементной мельницы

**Оконное приложение Python (Tkinter), не сайт.** Предназначено для имитации помола цемента и прогнозирования износа мелющих тел разных размеров, форм и материалов. Excel с таблицами и диаграммами формируется через `XlsxWriter`; графики в окне — `Matplotlib`.

> **Исследовательский прототип:** коэффициенты износа и кинетики помола требуют калибровки по производственным наблюдениям. Значения R0,08, R0,045 и особенно «Блейн-прокси» не являются лабораторными измерениями и не служат основанием для принятия решений без проверки технологом.

## Установка на Fedora

В Fedora для работы оконного интерфейса иногда требуется отдельно установить Tkinter:

```bash
sudo dnf install python3-tkinter
```

В корне репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Также можно запускать `python project/app.py`.

### Запуск в PyCharm

Откройте весь репозиторий `melnitsa-proj` как проект. В Run → Edit Configurations создайте конфигурацию **Python**: Script path — `.../melnitsa-proj/main.py`, Working directory — корень репозитория, Interpreter — `.venv/bin/python`. Затем нажмите обычную кнопку ▶ Run. **Streamlit и браузер не требуются.**

## Работа с приложением

1. Нажмите **«Импорт JSON»** и выберите `examples/mill3_input.json` либо `examples/two_drums_input.json`. По умолчанию уже загружен пример мельницы №3.
2. Измените количество самостоятельных барабанов, размеры камер, производительность, загрузку шаров и цильпебса, параметры износа.
3. Для редактирования ассортимента используйте вкладку **«Мелющие тела»**: каждой строке соответствует отдельный диаметр, материал и форма.
4. Укажите запланированные догрузки во вкладке **«Догрузки»**.
5. Нажмите **«Рассчитать»** — увидите графики потерь, диаметра, удельного износа, диаграмму помола по длине камер и рекомендации.
6. Нажмите **«Экспорт Excel»** — получите отчёт со встроенными графиками.
7. **«Импорт истории CSV»** загружает журнал производственных наблюдений и позволяет оценить базовый износ в г/т по массовому балансу (полная калибровка параметров этим не заменяется).

## Примеры — только входные данные

| Файл | Назначение |
| --- | --- |
| `examples/mill3_input.json` | Конфигурация двухкамерной мельницы №3 (демонстрационная) |
| `examples/two_drums_input.json` | Два самостоятельных барабана со своей геометрией и загрузкой |
| `examples/history_input.csv` | Журнал производства, догрузок и остаточной массы |

Примеры загружаются **через кнопки импорта**, не запускаются отдельными программами. Примеры не являются замерами предприятия.

## Структура

```text
melnitsa-proj/
├── main.py                     # Запуск рабочего окна
├── project/
│   ├── app.py                  # Дополнительная точка запуска
│   ├── desktop_app.py          # Весь оконный интерфейс
│   ├── model.py                # Математическое ядро Black Box
│   ├── calibration.py          # Оценка износа по заводскому CSV
│   ├── excel_export.py         # Excel с таблицами и диаграммами
│   └── blackbox_cli.py        # JSON-интерфейс для интеграции (не пример)
├── examples/                   # Только данные для импорта
├── docs/                       # Предметная область и формулы
├── tests/                      # Автоматические проверки
├── requirements.txt
└── README.md
```

### Отдельный Black Box для внешних систем

```bash
python project/blackbox_cli.py examples/mill3_input.json result.json
```

Это вспомогательный JSON-интерфейс для интеграции; пользователю оконного приложения он не нужен.
