# Black Box — имитационная модель цементной мельницы и износа мелющих тел

Это **рабочий исследовательский прототип**, а не сертифицированная модель конкретного предприятия. Содержит веб-интерфейс на Streamlit, отдельное Python-ядро, расчёт помола по фракциям и координате камеры, прогноз износа во времени, рекомендацию догрузки и выгрузку Excel с диаграммами. Демонстрационный пресет основан на исходной HTML-модели мельницы №3, но **не является измерениями производственного оборудования**.

## Быстрый запуск

Для Python 3.11+:

```bash
python -m pip install -r requirements.txt
python -m streamlit run project/app.py
```

В терминале появится адрес, обычно `http://localhost:8501`. Для запуска без браузера и получения образца Excel:

```bash
python project/run_example.py
```

Для подключения к внешнему Black Box через обмен JSON:

```bash
python project/blackbox_cli.py examples/example_config.json result_from_blackbox.json
```

Входом служит JSON параметров, результатом — JSON с временными рядами, диаграммой помола, итоговыми фракциями и рекомендациями. Обмен с конкретным промышленным ПО/АСУ ТП требует его формата/API и здесь **не заявляется реализованным**.

Для тестов:

```bash
python -m pip install pytest
python -m pytest -q
```

**Зависимость Excel:** общедоступная библиотека `XlsxWriter` (`pip install XlsxWriter`) из PyPI. Прежняя зависимость `artifact_tool_v2` удалена; экспорт работает без неё. Проект предназначен в том числе для Python 3.14 (подтверждена работа ядра и экспорта в среде сборки, а не в пользовательском окружении Fedora). В архив включён пример `examples/example_report.xlsx`.

| Состав загрузки | Журнал загрузок: тип, материал, диаметр, тоннаж | Площадь контакта, объём заполнения, удар/истирание |
| Измеренные диаметры и масса | Сортировка при остановке, обследования | Калибровка закона и проверка прогноза |

| R0.08, R0.045, Блейн | Лабораторные пробы, ситовой анализ, прибор Блейна | Верификация качества и настройка кинетики помола |

**Две камеры одного барабана:** задают один `D`, две длины `L1` и `L2`, толщину перегородки `Lпер`; программа определяет `L=L1+L2+Lпер`. **Два самостоятельных барабана:** каждый имеет собственные `D`, `L`, обороты, мощность и 1/2 камеры, загрузки каждой камеры вводятся отдельно.

## Производительность: измерение и оценки

1. **Приоритет — фактическое измерение:** `Q = Δмасса/Δвремя`, т/ч. Также можно использовать суммарный поток весовых дозаторов при установившемся материальном балансе.
2. **Оценка из мощности:** `Q≈P/Eуд`, где `P` — суммарная мощность приводов, `Eуд` — опытная удельная энергия (кВт·ч/т). Если задана только мощность мельницы без вентиляторов/сепаратора, нельзя сравнивать результат с полной удельной энергией линии.
3. **Оценка по Бонду:** `E_Bond=10·Wi·(1/√P80−1/√F80)` кВт·ч/т при F80/P80 в мкм, `Q≈P/E_Bond`. Это **приближение**: для цемента, многокомпонентной шихты, сепаратора и особой кинетики реальная энергия может существенно отличаться.

Конструкция и загрузка мельницы накладывают ограничения на достижимую Q, однако **единственной формулы Q только через D и L нет**. Систему сепаратора в текущем ядре моделируем лишь коэффициентом возврата, без функции разделения Тромпа.

## Формула износа: научная основа и выбранная реализация

Индекс `i` относится к отдельной фракции: камера, материал, форма и номинальный диаметр. Учтены **шары и цильпебс**; для цильпебса вводится отношение длины к диаметру `a=Lц/D`.

Для текущего диаметра `d_i` (метры) и плотности `ρ_i` (кг/м³):

- шар: `m_one=ρπd³/6`, `A_one=πd²`;
- цильпебс: `m_one=ρπa·d³/4`, `A_one=πd²(a+1/2)`.

Пусть `N_i` — число одинаковых тел, `Δ` — показатель типа закона износа. Контактная **взвешенная площадь**:

`w_i(t) = N_i A_i(d_i(t)) × (d_i(t)/0.050 м)^Δ × F_i(t)`.

`F_i = Fматериала × Fформы × Fабразивности × Fчастоты × Fзаполнения × Fмощности × Fкамеры × Fсреды × Fкрупности × Fразмолоспособности`.

При этом в прототипе:

- `Fчастоты = (ψ/ψ_ref)^a`, где `ψ=n/nкр`, `nкр≈42.3/√D_барабана`;
- `Fзаполнения = (J/J_ref)^b`, `J=Vзагрузки_россыпью/Vкамеры`;
- `Fмощности = (Pуд_загрузки/13 кВт/т)^c` (приближение, требует калибровки);
- `Fматериала`: сталь 1.00, высокохромистый чугун 0.67, серый чугун 1.33 **только стартовые гипотезы из прежней HTML-модели**;
- `Fформы`: для цильпебса 1.08 **допущение**;
- `Fкрупности=(d_геом.ср / d_реф)^e` с ограничением отношения 0,5–2; `Fразмолоспособности=(1/G)^h`. Степени `e,h` задаются пользователем; связь требует испытаний;
- влияние температуры/влажности — **эмпирические множители**, не физически доказанная функция.

`W_ref = Σ N_i A_i(d_i0) × (d_i0/0.050 м)^Δ` — опорная поверхность в исходной загрузке **без** поправок `F_i`. Суммарная скорость истирания:

`Mdot_wear [кг/ч] = Q_product [т/ч] × G0 [г/т] / 1000 × (Σw_i/W_ref)`.

Потеря массы конкретной фракции:

`dm_i/dt = -Mdot_wear × (w_i/Σw_j)`.

После каждого шага интегрирования текущий размер определяется сохранением формы и плотности:

`d_i(t) = d_i0 × (m_i(t)/m_i0)^(1/3)`.

Для постоянного `F` и при `Δ=0` это соответствует **поверхностной схеме** `dm_одного_тела/dt ∝ d²`, то есть относительно постоянной скорости уменьшения диаметра. При `Δ=1` зависимость имеет форму `∝ d³`, что соответствует одному из альтернативных законов в литературе. Реальные показатели бывают различны, поэтому нельзя заранее объявлять `Δ=0` истиной для любых материалов.

**Отдельный коэффициент фракции во времени:** `G_i(t)=G0×w_i(t)/W_ref` г/т цемента; **суммарный:** `G(t)=ΣG_i(t)`. Эти величины включены в Python-результат и отдельный Excel-график.

**Важно:** размер — самостоятельный фактор уже в `A_i(d)` и размере тела. Использовать отдельный произвольный `sizeF` без обоснования не требуется. Коэффициент `G0` обозначает **базовый удельный износ**, а вычисляемая мгновенная величина `G(t)=1000·Mdot_wear/Q_product` меняется по мере износа/изменения режима.

Указанные формулы — **выбранная для прототипа инженерная комбинация** известного семейства законов износа и эмпирических поправок; комплексная формула `F_i` как единое целое **не получена из конкретной научной статьи**, и её коэффициенты нельзя считать доказанными без калибровки.

## Функция помола и диаграмма по длине

Гранулометрический состав представлен 10 классами (`>40` … `<0.045` мм). В каждой камере вычисляются: объём, масса и `J`, средневзвешенный диаметр, скорость в долях критической. Модельная скорость разрушения каждой крупной фракции зависит от совпадения размера тела с оптимальным диаметром воздействия и от истирания тонких классов; количество разрушаемых частиц за `dt` задаётся `ΔM_i=M_i·[1−exp(−S_i·dt)]`. Материал распределяется по более мелким классам согласно упрощённому breakage distribution.

Материал последовательно перемещается через камеры. Программа формирует **14 виртуальных осевых проб** и рассчитывает `R0.08`, `R0.045` и остатки на остальных ситах. `Блейн-прокси = B0 + k_B×доля(<0.045)` **не заменяет лабораторного определения удельной поверхности**. Параметры `breakage_k`, `fines_attrition_k` подстроены для приблизительного воспроизведения поведения предыдущего HTML-проекта в демонстрационном пресете, а **не подтверждены полевыми опытами**.

## Рекомендация по догрузке

Рекомендация формируется **по каждой начальной фракции** (барабан/камера/материал/тип/Ø), когда её масса упала более заданного порога. Догрузка = исходная масса − оставшаяся, затем пересчёт в целое количество **новых** тел того же начального размера. В таблице сохраняются исходная/текущая масса, диаметр, износ и требуемые штуки.

Это **восстановление стартовой загрузки, не математическая оптимизация помола**. Перед реальной догрузкой необходимо проверять ограничения камеры по J, эффективность и паспорта футеровки; иначе поддержание изначального ассортимента может оказаться неоптимальным.

## Калибровка на предприятии

### Минимум, достаточный для настройки G0

За несколько **устойчивых** периодов запишите массу загрузки в начале/конце, все догрузки, **фактически выбракованную** массу и выпуск цемента:

`wear_t = M_start_t + M_reload_t − M_end_t − M_removed_t`.

`GMCR [г/т] = wear_t×10^6 / production_t`.

Используйте вкладку **«Калибровка по историческим данным (CSV)»** и шаблон журнала. Простое отношение часто искажается погрешностью оценки загрузки; сам журнал догрузок без баланса **не измеряет мгновенный износ**.

### Для проверки зависимости от разных параметров

Нужны независимые наблюдения при разных `Q`, `P`, `n/nкр`, `J`, абразивности и разных материалах/размерах. Для каждой фракции при остановках полезно измерять `D_start`, `D_end` и число оставшихся тел/массу. На тренировочных периодах подобрать `G0`, `Δ`, `a`, `b`, `c`, коэффициенты материалов путём минимизации ошибки между прогнозной и наблюдаемой потерей массы, например, `Σ (M_pred−M_obs)^2`. **Не оценивать одновременно все коэффициенты по одному периоду**: они неидентифицируемы. Затем отдельно проверить ошибку на отложенных периодах, остатки для грансостава и отклонение `R0.08/R0.045/Блейн`.

## Состав файлов

- `blackbox_cli.py` — машинный JSON-интерфейс для внешних систем.
- `app.py` — веб-интерфейс Streamlit (ввод геометрии, режима, сырья, фракций; графики и выгрузка).
- `model.py` — независимая функция Black Box `simulate_wear(config)` и расчёт помола `quality_at(...)`.
- `calibration.py` — расчёт наблюдаемого GMCR по CSV-журналу.
- `excel_export.py` — формирование `.xlsx` с диаграммами с помощью `XlsxWriter`.
- `run_example.py` — генерация примера без веб-интерфейса.
- `example_config.json` — демонстрационные входные параметры.
- `examples/example_report.xlsx` — заранее построенный Excel.
- `tests/test_model.py` — проверки баланса массы, геометрии, материалов, режимов Q и т. д.

В Excel доступны вкладки `Сводка`, `Износ_во_времени`, `Диаметры_во_времени`, `Масса_фракций_по_времени`, `Износ_по_фракциям_г_т`, `Фракции_износ`, `Догрузка`, `Тонкость_во_времени`, `Диаграмма_помола`, `Геометрия`, `Источники`. Excel показывает рассчитанные временные ряды; для повторного расчёта после изменения входных параметров нужно снова запускать Python-модель.
