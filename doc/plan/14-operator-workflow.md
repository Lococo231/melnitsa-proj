# Фаза 14 — операторский workflow симуляции

## Цель
Упростить пользовательский сценарий работы технолога:
1. задать исходные параметры;
2. запустить симуляцию отрезка работы;
3. изменить входные параметры;
4. снова запустить симуляцию;
5. получить непрерывную историю расчёта по нескольким отрезкам.

## Что меняется
- убираются поясняющие баннеры;
- в меню добавляются «Как работает?» и «Экспорт»;
- во вкладке «Симуляция работы» появляется журнал симуляций;
- повторный запуск по кнопке «Пуск» формирует новый сегмент и продолжает график.
