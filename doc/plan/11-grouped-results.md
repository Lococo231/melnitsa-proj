# Фаза 11 — группировка результатов помола и мелющих тел

## Назначение

Упростить навигацию справа, сохранить модельные данные и устранить
непреднамеренное растяжение последней колонки таблицы проб.

## Структура интерфейса

- «Контроль помола»: (1) диаграмма полного остатка по длине мельницы;
  (2) табличные контрольные пробы, R0,08 и R0,045 остаются разными ситами.
- «Мелющие тела»: (1) начальная загрузка и состав по камерам;
  (2) фактический и прогнозный износ фракций, использующий хронологию.
- Старые корневые страницы 1/2/4/7 переподключены через
  вложенный QTabWidget с сохранением прежних индексов.
  Позиции 4/7 скрыты, но НЕ удаляются и не используются как новая модель.

## Таблица проб

Показатель R0.045 в строках уже присутствовал — проблема была в
QHeaderView.StretchLastSection, расширявшем только последнюю колонку.
Использовать Stretch для всех числовых колонок одинаково и
Interactive для «Точка», «Расстояние», «Камера».
При недостаточной ширине должен появляться горизонтальный скролл.
Переводить десятичную точку на запятую только в заголовке.

## Проверки и ограничения

- Локально: pytest tests/test_staged_results_qt.py при PySide6.
- Проверить Windows/PyCharm, вкладки, переключение этапов и
  соответствие R0,045 исходным расчётным пробам.
- Не восстанавливать GitHub Actions. Не коммитить без прямой команды.
