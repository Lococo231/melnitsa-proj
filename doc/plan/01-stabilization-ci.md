# Фаза 1 — локальная проверка и стабильность

**Актуальный статус (08.11.2026):** пользователь отключил автоматические тесты GitHub Actions. Ранее запланированная матрица CI больше не является целью. Workflow `.github/workflows/tests.yml` удалён; `tests/`, `pytest.ini` и `requirements-dev.txt` сохранены для запуска тестов вручную.

## Работа без GitHub Actions
1. Проверять существующие unit, CLI/integration и Qt smoke-тесты локально командой `QT_QPA_PLATFORM=offscreen python -m pytest -q`.
2. Устанавливать зависимости для тестов с `python -m pip install -r requirements-dev.txt`.
3. После изменения модели запускать затронутые тесты материального баланса, качества и импорта/экспорта.
4. Для графических изменений проверять QApplication в реальном рабочем окружении Fedora / Windows и ручное взаимодействие с интерфейсом.
5. Не восстанавливать GitHub Actions workflow без явной отдельной команды пользователя.
