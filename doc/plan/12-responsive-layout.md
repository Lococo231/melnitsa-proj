# Фаза 12 — адаптивная ширина и чёткость графиков

## Проблема

Старый `QSplitter` меняет размеры боковых областей, но перенесённые из отдельных
`QScrollArea` формы остаются с прежними требованиями к минимальной ширине:
`QFormLayout` по умолчанию располагает подпись и числовое поле рядом, даже если
для этого уже нет места. Предыдущий пакет этапных вкладок дополнительно задавал
`window.left.setMinimumWidth(345)`. Из-за этого панель и её содержимое
плохо адаптируются при перемещении границы влево/вправо.

Для «Износа фракций» использовались PNG 1188×242, без учёта фактических размеров
панели. `HourPlotImage(QLabel)` включал `setScaledContents(True)` и растягивал
растровое изображение по двум независимым осям; текст и линии искажались.

## Реализация

1. `responsive_ui.py` устанавливается после `staged_results_ui.py`,
   работает с оригинальными виджетами и сигналами.
2. У больших контейнеров устранён принудительный минимум ширины,
   `QScrollArea.widgetResizable=True`; ограничение размеров остаётся
   внутри таблиц, а не у целой страницы.
3. При изменении ширины форма переключается между `WrapAllRows` и
   `WrapLongRows`, сохраняя поля, их значения и обработчики событий.
4. Во вкладке «Износ фракций» добавлен выбор **одного** показателя:
   диаметр, масса или удельный износ. Раздельные графики больше не
   спрессовываются в три маленькие изображения.
5. `multicore_render.py` создаёт PNG под фактический размер панели с
   удвоенной плотностью пикселей (целевой размер передаётся рабочему процессу).
   Qt рисует их через `QPainter.drawImage`, сохраняя пропорции; курсор
   рассчитывается внутри фактически нарисованного прямоугольника.
6. При изменении размера график перерисовывается с паузой, чтобы не
   запускать повторные мультипроцессные задания на каждый пиксель движения.

## Проверка

- Синтаксис модулей + повторная установка.
- Чистый Matplotlib Agg: PNG с заданными размерами, без импорта Qt.
- Реальный Windows/PySide6: узкие/широкие панели, таблица проб,
  выбор камеры и метрики, показ часа, переключение вкладок.
- Потребление CPU/памяти при 4K и повышенном масштабе Windows.

## Не затрагивается

Формулы кинетики помола, физическое моделирование Q и критерии цемента.
Многопроцессный расчёт догрузки остаётся прежним. Не восстанавливать CI
GitHub Actions; коммит только по команде пользователя.
