# Фаза 13 — адаптивное разрешение всех графиков

## Причины проблем

- `multicore_render.py` ранее строил PNG с фиксированным `Figure(figsize=(10.8, 2.2), dpi=110)`. Изменение ширины `QSplitter` не меняло количество пикселей диаграммы.
- `HourPlotImage` был `QLabel` с `setScaledContents(True)`, поэтому графики и текст искажались; это исправлено в базовом модуле `responsive_ui`.
- Догрузочные/износные серии используют Matplotlib Agg вне GUI-потока, а основное окно Qt изменяет размеры в GUI-потоке. Перерисовку нужно делать после получения размера *видимого* контейнера, не при каждом `resizeEvent` по отдельности.

## Реализация

1. `responsive_ui.py` и `staged_results_ui.py` обеспечивают перенос форм, горизонтальное заполнение и этапную навигацию.
2. `multicore_render.render_timeline_images(target_size=...)` передаёт **всем** задачам Agg удвоенный размер видимой панели, включая симуляцию, историю, фракции, прогноз. Изображения сохраняют пропорции и не размываются при небольших изменениях.
3. Новый `adaptive_graphs_ui.py` устанавливается последним. Слушает `Resize`/`Show` основного окна, `QSplitter` и графических панелей. С дебаунсом 360 мс перерисовывает **только открытые диаграммы** в рабочем пуле и через `ProcessPoolExecutor(spawn)`.
4. Служебные сигналы существующего `multicore_ui` используют теги `adaptive:<group>`, чтобы не запускать старые обработчики для неизвестных групп; новый обработчик привязывает размеры к номеру генерации симуляции и игнорирует устаревшие расчёты.
5. Для графиков Matplotlib QtAgg используется `canvas.draw_idle()`: FigureCanvasQTAgg сам пересоздаёт растровое представление в соответствии с DPI монитора и размером окна.
6. График фракций остаётся одноэкранным (выбор: размер/масса/удельный износ); его фоновый перерендер обеспечивает `responsive_ui`. Механизм не меняет физические формулы.

## Риски и локальная проверка

- До выпуска проверить Windows 125%, 150%, 200% DPI; разные размеры левой и правой панелей, перетаскивание разделителя, переключение этапов, 4K.
- При большом количестве серий PNG на 4K может занимать память — ограничить пиксельные размеры и число одновременно строящихся кадров.
- Проверить устаревшие результаты при изменении параметров во время фонового рендеринга.
- Локальные проверки: `tests/test_all_graph_resolutions.py`, `tests/test_all_graphs_qt.py`, все прежние `test_responsive_*` и `test_staged_*`.
- GitHub Actions отключён по просьбе пользователя и не должен восстанавливаться.
