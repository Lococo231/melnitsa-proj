# Qt Widgets: организация рабочего места оператора (13.11.2026)

## Проверенные источники

1. Qt for Python, Layout Management: https://doc.qt.io/qtforpython-6/overviews/qtwidgets-layout.html
   - `QFormLayout` для полей, `QVBoxLayout` и `QGroupBox` для логически связанных секций.
   - Сохранять исходные `QWidget` при перегруппировке: иначе теряются существующие сигналы, виджеты и редактируемые данные.
2. Qt for Python, QSplitter: https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html
   - `hide()` элемента передаёт ширину соседней панели. Существующий QSplitter сохраняется, состояние переключателей не заменяется новой сеткой.
3. Qt for Python, QStackedWidget: https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QStackedWidget.html
   - Для множества взаимоисключающих диаграмм использовать один видимый график и выбор по `QComboBox` (семантически аналог `QStackedWidget`). Здесь один `HourPlotImage` переиспользуется при выборе разных PNG.
4. Matplotlib, Interactive figures and asynchronous programming: https://matplotlib.org/stable/users/explain/figure/interactive_guide.html
   - Считать данные и PNG в фоновых процессах; рисовать `QWidget` только в Qt GUI-потоке.
   - Использовать `draw_idle` для отложенного обновления вместо синхронной полной перерисовки.

## Решение в приложении

- Одна вертикальная прокручиваемая форма, секции, читаемые заголовки, компактные отступы.
- Шесть графиков в одном месте с выпадающим списком, вместо шести одновременно видимых областей.
- Полноценный автоматический журнал с отдельными таблицами и графиками изменений, без ручного заполнения журнала.
- Подготовка будущих операций из симуляции. В журнале отображаются только операции, уже записанные в конфигурацию и учтённые в траектории.
- Сохранение текущих индексов скрытых правых вкладок для совместимости с сигналами старой версии. В перспективе нужен рефакторинг от числовых индексов к именованным страницам.

## Границы уверенности

- Износ, тонкость помола, прокси Блейна и независимая заданная Q остаются эмпирическими/условными. Применение предложенных догрузок требует подтверждения технологом.
- Дискретный комбинированный поиск до трёх действий не является глобальным оптимумом. Программа выбирает наиболее долгий период нахождения в пределах целей **среди проверенных комбинаций**.
- Изменение паспорного диаметра барабана в журнале моделирует реконструкцию, а не регулировку во время работы.
