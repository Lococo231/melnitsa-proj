# Исследование: горизонтальная адаптивность PySide6 и качество PNG графиков

## Найденные проблемы в исходниках `melnitsa-proj`

1. В `qt_app.py` используется горизонтальный `QSplitter`; он действительно
   перераспределяет размер внешних панелей. Но реальные формы были вынесены
   из первоначальных `QScrollArea` и помещены внутрь объединённых секций
   `workspace_ui.py`. У `QFormLayout` ранее не был установлен
   `RowWrapPolicy`: подпись и поле оставались на одной строке и влияли на
   минимальный размер контейнера. Пользователь видел горизонтальную
   прокрутку, а не адаптацию поля по ширине.
2. В предыдущем обновлении этапных вкладок присутствовал
   `window.left.setMinimumWidth(345)`, противоречащий требованию
   свободно менять ширину левой колонки.
3. `multicore_render.py` создавал каждый график фракций как PNG
   `10.8×2.20 in × 110 dpi = 1188×242 px`. Независимо от размера
   окна график занимал один из трёх вертикальных слотов.
4. `multicore_ui.HourPlotImage` вызывал `QLabel.setScaledContents(True)`.
   Это заставляло PNG растягиваться на всю геометрию QLabel без сохранения
   соотношения сторон, деформируя оси, шрифты и толщину линий.
5. Курсор времени использовал полные размеры QLabel, а не реальную
   позицию картинки. При изменении aspect ratio он мог не попадать на X.

## Рекомендации Qt и применённые правила

- [Qt: QScrollArea](https://doc.qt.io/qt-6/qscrollarea.html): включать
  `widgetResizable` и согласовывать child size policy / layout size hints.
- [Qt: Layout Management](https://doc.qt.io/qt-6/layout.html): геометрия
  зависит от `minimumSizeHint`, `sizePolicy`, stretch и height-for-width;
  `QFormLayout` должен переносить длинные строки при недостатке ширины.
- [Qt: QSplitter](https://doc.qt.io/qt-6/qsplitter.html): splitter меняет
  внешние размеры, но виджеты ограничены своими минимумами.
- [Qt: QLabel](https://doc.qt.io/qt-6/qlabel.html): `scaledContents=True`
  растягивает картинку на всю доступную область; это не решение для
  графиков, где важно сохранить соотношение осей.
- [Qt: QPixmap / HiDPI](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QPixmap.html):
  для Retina/HiDPI используйте изображения с достаточным количеством
  физических пикселей и корректным масштабированием.

## Выбранное решение

- Убрать жёсткий `minimumWidth` и задать контейнерам размеры как Ignored
  горизонтально; оставлять горизонтальную прокрутку лишь в длинных таблицах.
- Переключать `QFormLayout` между `WrapAllRows` для узкой панели и
  `WrapLongRows` для широкой, обновляя layout только после debounce таймера.
- Показывать один из 3 графиков износа; при смене размера создавать PNG
  в фоне под фактическое соотношение ширина/высота с 2× плотностью пикселей.
- Отображать QImage через QPainter без геометрических искажений, курсор
  времени наносить относительно вписанного изображения.

## Проверка

Чистый Matplotlib Agg создаёт PNG под заданный размер. Установщик
повторно применим. Реальный PySide6 на Windows остаётся внешней проверкой,
поскольку в текущем исполняющем окружении библиотеки PySide6 нет.
