# Технологические карты из исходного HTML

Источник: сохранённый в личной библиотеке `1233223_fixed_norm.html`, блок `var CEMENT`, проверен 2026-11-08. Значения ниже переносятся как **цели технологической карты**, а не обязательные требования ГОСТ.

| Ключ | Вид цемента | R0,08, % | R0,045, % | Блейн-прокси, см²/г |
|---|---|---|---|---|
| 425N | ЦЕМ I 42,5Н | ≤2.0 | 33–36 | 3200–3500 |
| 425B | ЦЕМ I 42,5Б | ≤1.5 | 30–34 | 3500–3800 |
| 525N | ЦЕМ I 52,5Н | отдельной границы нет | 28–32 (контрольное R0,045 ≤32) | 3800–4200 |
| 2A425 | ЦЕМ II/А-Ш 42,5Н | ≤3.0 | 34–38 | 3000–3400 |
| 2AI425 | ЦЕМ II/А-И 42,5Н | ≤3.0 | 34–38 | 3000–3500 |

В HTML часть границ обозначена как «тип.» для R0,045; это технологические ориентиры. ГОСТ 31108-2020 (https://protect.gost.ru/gost/details/540e6d41-0aa3-4280-a123-b983634fa349) устанавливает требования к цементу, включая прочность, сроки схватывания и другие показатели, но приведённые здесь интервалы не должны заявляться как норматив ГОСТ. ГОСТ 310.2-76 (https://protect.gost.ru/gost/details/e10a0167-1772-4d6c-976a-acf7488c08f9) описывает **методы измерения** тонкости помола.

Граница может быть только верхней (R0,08) или интервалом. В модуле `production_planning.PROFILES` для 52,5Н нет искусственного порога R0,08: контрольный показатель взят из HTML — R0,045. Контроль производительности — отдельно заданный минимум, а не требование сертификата.

**Важное ограничение физики:** `quality_at()` в `model.py` — кинетический прототип, а `blaine_proxy = base + scale * доля(<0.045 мм)` — прокси, без прямой лабораторной привязки; поэтому прогноз не заменяет лабораторную пробу. Модель не знает фактического изменения Q после вмешательства. До ввода в эксплуатацию требуется калибровка на истории смен с измерениями R0,08, R0,045, Блейна, загрузки, износа, выбраковки и производительности.
