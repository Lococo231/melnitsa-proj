# Аудит формульной составляющей цементной мельницы — 09.11.2026

Источники сверены с математическим кодом `model.py`, `shift_simulation.py`, `operation_timeline.py`, `production_planning.py`, `calibration.py`. Статус «подтверждено» относится к **математической форме и размерности**, а не к калибровке на конкретном заводе.

## 1. Геометрия и целочисленный учёт (подтверждено)

- Камера: `V = π × D² × L / 4`, D и L в метрах, V в м³.
- Шар: `m = ρ × π × (d/1000)³ / 6`, кг; ρ в кг/м³, d в мм.
- Цильпебс цилиндрической формы: `m = ρ × π × (d/1000)³ × (L/D) / 4`, кг. Для цилиндра полная геометрическая площадь `S = π d² (L/D + 1/2)`, d в метрах.
- Целочисленная загрузка `N = round_half_up(M_t × 1000 / m_шт)`, действительная масса `M_t = N × m_шт / 1000`. При износе количество не дробится; выбраковка уменьшает N.
- Заполнение `J = Σ(m_i/ρ_i) / (p × V)` — модельная приближённая укладка с `p=0,585` или `0,62`, а **не универсальный технологический закон**. Пределы J=0,18–0,40 требуют проверки по паспорту мельницы.

Источник по объёму и критической скорости: CII Formula Handbook: https://energy.greenbusinesscentre.com/mv/greencementech/pub24/4.%20Formula%20Handbook%20for%20cement%20industry_v3.0.PDF ; AusIMM MillCalc: https://www.ausimm.com/globalassets/insights-and-resources/minerals-processing-toolbox/millcalcv2a.pdf

## 2. Скорость и износ (разграничение подтверждённого и калибруемого)

- `n_кр≈42,3/√D` об/мин при D в метрах — стандартная инженерная оценка. Более строгая оценка учитывает диаметр шара `D−d` и внутренний диаметр по футеровке; фактическое вращение требует измерения.
- `w_i=N_i S_i(d_i)(d_i/d_ref)^δ × F_i` — **авторская эмпирическая схема**, не установленный общий закон. Множители мощности, температуры, влажности, твёрдости и контактного действия должны быть откалиброваны.
- Массовый баланс: `масса_нач + догрузки = масса_кон + истирание + выбраковка`. Удельный износ: `GMCR_г/т = потеря_т ×10^6 / выпуск_т`. Формула в `calibration.py` соответствует балансу.
- Перемена диаметра с кубическим корнем `d=d0 × (M/M0)^(1/3)` корректна для сфер/цилиндров при **неизменном числе и пропорциях L/D**. Для цилиндров с износом только по торцам/бокам нужен отдельный закон изменения геометрии.

Bürger et al. (2018): https://doi.org/10.1016/j.mineng.2018.09.004 — экспериментальная модель износа и оговорка об отдельных законах скоростей.

## 3. Поток и энергетика (подтвержденные единицы)

- Производительность `Q=M/Δt` т/ч, `E_уд=P/Q` кВт·ч/т. Для оборотной нагрузки `F_внутр=Q×(1+r)` в упрощённом стационарном балансе.
- Время пребывания `τ_мин=60×M_hold/F_внутр` корректно по размерности, **но является приближением среднего времени без распределения RTD и сепаратора**.
- По Бонду: `E=10 Wi(1/√P80 −1/√F80)` при P80/F80 в мкм, E в кВт·ч/т. `Wi_экспл=E / [10(1/√P80 −1/√F80)]`. Лабораторный Wi по тесту Бонда и эксплуатационный Wi разделены — правильно. Для цемента нужны поправки эффективности, тонкости и схемы сепарации; простой Бонд не доказывает производительность.

Источники: Global Mining Guidelines Group, *Determining the Bond Efficiency of Industrial Grinding Circuits*: https://gmggroup.org/wp-content/uploads/2024/07/GUIDELINE__Determining-the-Bond-Efficiency-of-Industrial-Grinding-Circuits_2021.pdf ; The Cement Grinding Office, *Cement Ball Mill Technology*: https://www.thecementgrindingoffice.com/Preview.pdf

## 4. Грансостав, кинетика и ситовые остатки (частично подтверждено)

- Остаток на сите R(s) — суммарная массовая доля частиц крупнее размера отверстия. Это корректная логика функции `cumulative_residue`; R(s) не увеличивается с ростом s.
- Распределение размеров в `quality_at` состоит из десяти псевдофракций, кинетика `Δm_i=m_i(1−exp(−k_iΔt))`; это дискретная 1-го порядка схема, сохраняющая массу **если вероятности фрагментации нормированы**. `k_i` и `fragmentation(i)` — не измеренные коэффициенты.
- Исправление производительности: `media_impact(sub,MID[i])` вычисляется **один раз на пару (камера, класс) для одного контрольного состояния**, поскольку массив `sub` внутри этой функции не меняется на осевых шагах. Эквивалентность старому алгоритму следует из отсутствия зависимости `rate` от `j`.
- В реальных непрерывных мельницах для предсказания нужны экспериментальные breakage/selection functions, распределение времени пребывания и учёт сепарации.

Источники: https://www.mdpi.com/2674-0516/3/2/12 ; https://doi.org/10.3390/met10121687 ; https://www.tandfonline.com/doi/full/10.1080/19236026.2023.2204708

## 5. Блейн и нормы цемента — ограничения (критично)

- Текущий `B_proxy = lab_blaine_base + lab_blaine_scale × доля(<0,045 мм)` — **только модельный индекс**, не метод Блейна. По EN 196-6 удельную поверхность измеряют воздухопроницаемостью уплотнённого слоя и сравнением с эталоном, поэтому ни размерность, ни диапазон модели не подтверждают истинный Блейн.
- Целевые интервалы R0,08/R0,045/Blaine взяты из сохранённого пользовательского HTML. Это **технологические карты**, а не обязательные диапазоны ГОСТ для всех цементов.
- Смена марки цемента меняет применимую технологическую карту, но не является автоматическим изменением минералогического состава клинкера, дозировки гипса, корректирующих добавок или свойств конечного цемента.

EN 196-6:2018 (official standard excerpt): https://cdn.standards.iteh.ai/samples/60528/2c57afb4157d4d53ae2cd3/SIST-EN-196-6-2019.pdf ; national standards bodies: https://www.sis.se/en/produkter/construction-materials-and-building/construction-materials/cement-gypsum-lime-mortar/ss-en-196-62019/

## 6. Алгоритм многопроцессного расчёта — проверки

- Базовая история считается один раз. В точке перед первым отклонением сохраняются `cohorts`, динамическая `operating cfg`, накопленный износ.
- Для каждого кандидата расчёт начинается **после уже исполненных в этот час событий**, без повторения прошлого; будущие события применяются по часам. При первой недопустимой контрольной точке кандидат прекращает расчёт.
- Независимые кандидаты оцениваются в `ProcessPoolExecutor` с `spawn` на максимум четырёх процессах; выбор по `(часов в пределах, -масса операции)` остаётся детерминированным.
- Возможные нарушения **между** дискретными контрольными точками остаются вне гарантий; их нельзя исключить параллельностью. Сохранение Q при догрузке не моделируется.
- Программный научный аудит не подменяет экспериментальной валидации и идентификации параметров по данным завода.
