# Анализ области: как обычно показывают работу цементной шаровой мельницы

Ключевые наблюдения по инженерным описаниям и обзорам:

1. Вращение и измельчение зависят от режима движения мелющих тел — cascading и cataracting. При каскадном режиме тела перекатываются по поверхности заряда; при cataracting часть тел падает по баллистическим траекториям и создаёт ударное дробление. Для промышленных цементных мельниц характерно сочетание этих режимов, а при слишком высокой скорости начинается центрифугирование, что вредно для помола.
2. В двухкамерной цементной мельнице первая камера обычно отвечает за более грубое дробление и содержит более крупные шары; вторая камера — за тонкий помол и содержит более мелкую загрузку.
3. Между камерами располагается диафрагма/перегородка, которая удерживает крупные тела и пропускает материал.
4. В продольных схемах обычно показывают: подачу слева, две камеры, поток материала по длине, выход продукта справа, а также характер заряда внутри камер.
5. Для визуализации в приложении не нужен настоящий DEM: достаточно достоверно показать функции камер, направление потока и изменение размера частиц.

Практическое решение для приложения:
- поперечный разрез оставлен как 2D контактная демонстрация с ударами и истиранием;
- продольный разрез переделан под типовую компоновку двухкамерной мельницы;
- вычисление кадров вынесено в фоновые потоки, чтобы GUI не считал физику в `paintEvent`.
